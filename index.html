Changing a site

  1. Accept the one GitHub invitation. One repo, one accept, permanent — every site here and every site added later is already inside it.
  2. Open claude.ai/code and sign in with your own Claude account.
  3. Pick the rebuilds repo, name the site folder, and say what to change in plain English.
  4. Wait about a minute, then reload the site. Add ?v=2 to the URL if your phone shows the old version.
